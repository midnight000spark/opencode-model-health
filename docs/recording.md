# Запись демо

Демо записывается из живого OpenCode V2, а не генерируется. Плагин не печатает
ключи, но перед записью всё равно убедись, что в терминале нет секретов,
экспортированных переменных и открытого `cli.json`.

## Что нужно

- Bun и OpenCode V2 с настроенным провайдером;
- провайдер с небольшим списком моделей (5–15), чтобы GIF был коротким;
- [`vhs`](https://github.com/charmbracelet/vhs) для записи;
- по желанию `gifsicle` для сжатия.

## Запись

Из корня репозитория:

```sh
vhs docs/demo.tape
```

Сценарий лежит в [`demo.tape`](demo.tape): запуск `opencode`, команда
`/models-health`, ожидание скана, открытие деталей первой модели, возврат и
закрытие. Если скан у провайдера дольше 20 секунд, увеличь `Sleep` после
`Enter` в конце сценария.

## Проверка результата

- размер `docs/demo.gif` — желательно меньше 5 МБ;
- в кадре нет ключей, email и других личных данных;
- видно прогресс, список результатов и экран деталей.

Сжатие:

```sh
gifsicle -O3 --lossy=80 docs/demo.gif -o docs/demo.gif
```

После записи замени текстовый placeholder в разделе «Демо» README на:

```md
![Демо: проверка моделей](docs/demo.gif)
```

И закоммить `docs/demo.gif` вместе с обновлённым README.
