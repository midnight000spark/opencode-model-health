# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Fixed
- `reachable` больше не считается успехом: он вместе с новым `skipped` образует
  нейтральную корзину (`N нейтр.`), а в `✅` входят только HTTP 2xx.
- Токен-лимитная эвристика не срабатывает на `unsupported/unknown/... max_tokens`:
  такой ответ остаётся `нет доступа`, а не «модель отвечает».
- Модели, доступные только через `openai/responses`, не отбрасываются и не
  проверяются не тем протоколом, а показываются как `➖ не проверяется`.
- Кэш привязан к `baseURL` и SHA-256 fingerprint ключа: смена аккаунта
  больше не показывает чужие результаты.
- `Esc` во время скана отменяет его через `AbortController` (тост «Проверка
  отменена», без записи в кэш).
- Точное значение ключа вырезается из текста ошибок до применения regex-правил;
  CLI маскирует и сообщения о фатальных ошибках.

### Changed
- `apiKey` опционален: для Ollama/LM Studio/vLLM заголовок `Authorization` не
  отправляется.
- README: `cli.json` с `{package, options}` — основной способ подключения;
  описаны ограничения (Chat Completions, provider `headers`/`body`/
  `compatibility`, remote TUI).

## [0.1.0] - 2026-11-06

Первый публичный релиз.

### Added
- Команда `Models: health check` (`/models-health`, `<leader>mh`): проверка моделей
  провайдера минимальным `chat/completions`-запросом.
- Живое окно прогресса (Solid-компонент) с выделением имён моделей и счётчиком.
- Диалог результатов: сортировка «проблемы сверху», поиск, переключение режима
  `текст`/`все`, повторный скан.
- Экран деталей модели по `Enter` с возвратом к списку.
- Динамическое обнаружение списка моделей через `GET /models` с фильтрацией
  не-чат моделей и фолбэком на конфиг OpenCode.
- Headless-CLI (`bun run src/cli.ts`) с `--json`.
- Кэш результатов с TTL.

### Security
- Ключ используется только в заголовке `Authorization` и никогда не логируется.
- Причины ошибок маскируются (`Bearer`, `sk-…`, `user:pass@`, `api_key=…`) до
  показа, вывода в `--json` и записи в кэш.
