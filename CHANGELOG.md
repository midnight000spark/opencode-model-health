## [0.1.0] - 2026-11-06

Первый публичный релиз.

### Added
- Команда `Models: health check` (`/models-health`, `<leader>mh`): проверка моделей
  провайдера минимальным `chat/completions`-запросом.
- Живое окно прогресса (Solid-компонент) с выделением имён моделей и счётчиком.
- Диалог результатов: сортировка «проблемы сверху», поиск, переключение режима
  `текст`/`все`, повторный скан.
- Экран деталей модели по `Enter` с возвратом к списку.
- Динамическое обнаружение списка моделей через `GET /models` с фильтрацией
  не-чат моделей и фолбэком на конфиг OpenCode.
- Headless-CLI (`bun run src/cli.ts`) с `--json`.
- Кэш результатов с TTL.

### Security
- Ключ используется только в заголовке `Authorization` и никогда не логируется.
- Причины ошибок маскируются (`Bearer`, `sk-…`, `user:pass@`, `api_key=…`) до
  показа, вывода в `--json` и записи в кэш.
